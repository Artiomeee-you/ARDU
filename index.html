Виды микроконтроллеров

Плату выбирают не по принципу «какая лучше вообще», а по задаче: размер устройства, количество подключений, необходимость Wi-Fi и сложность проекта.

Лучший вариант для начала

Arduino Uno

ФОТО ARDUINO UNO

Удобная учебная плата: крупная, понятная маркировка контактов и огромное количество учебных примеров.

Когда выбирать

  • первые уроки робототехники;
  • работа на макетной плате;
  • простые датчики, светодиоды, сервоприводы;
  • когда размер устройства не важен.
Почему: ученику проще видеть подписи пинов и подключать провода. Поэтому Uno удобно использовать как основную учебную плату.
ПараметрArduino Uno
Логическое напряжение5 В
Цифровые пины14
Аналоговые входы6
Wi-Fi / BluetoothНет
Когда устройство должно быть маленьким

Arduino Nano

ФОТО ARDUINO NANO

Компактная плата. Классическая Arduino Nano по возможностям близка к Uno, но занимает значительно меньше места.

Когда выбирать

  • небольшой робот или готовое устройство;
  • плату нужно установить прямо на макетную плату;
  • проект уже проверен на Uno и его нужно уменьшить;
  • не хочется занимать много места внутри корпуса.
Почему: для учебного прототипа удобно начать с Uno, а затем перенести готовую схему на Nano и получить более компактное устройство.
ПараметрКлассическая Nano
Логическое напряжение5 В
Главное преимуществоКомпактность
Подходит для макетной платыДа
Wi-Fi / BluetoothНет
У Arduino Nano есть разные современные версии. Их характеристики могут отличаться от классической Nano.
Для большого количества устройств

Arduino Mega 2560

ФОТО ARDUINO MEGA

Большая плата с намного большим количеством входов и выходов, чем Uno.

Когда выбирать

  • нужно подключить много датчиков одновременно;
  • в проекте много кнопок, светодиодов, реле или сервоприводов;
  • нужно несколько аппаратных последовательных портов;
  • на Arduino Uno уже не хватает пинов.
Почему: Mega нужна не потому, что проект «сложный», а прежде всего тогда, когда физически не хватает входов и выходов.
ПараметрArduino Mega 2560
Логическое напряжение5 В
Цифровые пины54
Аналоговые входы16
Аппаратные Serial-порты4
Для беспроводных и более сложных проектов

ESP32

ФОТО ESP32

Семейство более мощных микроконтроллеров со встроенной беспроводной связью. Часто используется в устройствах, которые должны обмениваться данными по сети.

Когда выбирать

  • нужен Wi-Fi;
  • нужен Bluetooth;
  • данные должны передаваться на телефон или веб-страницу;
  • Arduino Uno уже недостаточно по возможностям;
  • создаётся устройство для интернета вещей.
Почему: ESP32 позволяет сделать, например, беспроводной датчик, веб-панель управления роботом или устройство, отправляющее показания по Wi-Fi.
ПараметрESP32
Логическое напряжение3,3 В
Wi-FiЕсть
BluetoothЕсть у многих вариантов ESP32
Количество пиновЗависит от конкретной платы
Важно: GPIO ESP32 работают с логикой 3,3 В и обычно не являются 5-вольт-толерантными. Перед подключением 5-вольтовых сигналов нужно проверять совместимость.

Мини-программа

Измерение расстояния
// Пины датчика расстояния
const int TRIG = 7;
const int ECHO = 6;

void setup() {
  // TRIG отправляет импульс
  pinMode(TRIG, OUTPUT);

  // ECHO принимает отражённый сигнал
  pinMode(ECHO, INPUT);

  // Запускаем Serial Monitor
  Serial.begin(9600);
}

void loop() {
  // Подготавливаем TRIG к новому импульсу
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);

  // Отправляем импульс длительностью 10 микросекунд
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);

  // Измеряем длительность сигнала ECHO
  long time = pulseIn(ECHO, HIGH);

  // Переводим время в расстояние в сантиметрах
  float distance = time * 0.034 / 2;

  // Показываем расстояние в Serial Monitor
  Serial.println(distance);

  delay(200);
}

Что означает код

const int TRIG = 7;
Запоминаем, что контакт TRIG подключён к D7.
pinMode(TRIG, OUTPUT);
D7 будет отправлять сигнал датчику.
pinMode(ECHO, INPUT);
D6 будет принимать сигнал от датчика.
pulseIn(ECHO, HIGH)
Измеряем длительность возвращённого импульса.
time * 0.034 / 2
Переводим время в расстояние в сантиметрах.

// PIR подключён к цифровому пину D2
const int PIR = 2;

void setup() {
  // Пин работает как вход
  pinMode(PIR, INPUT);

  // Включаем Serial Monitor

void loop() {

}

// Для этого примера нужна библиотека DHT
#include <DHT.h>

// Датчик подключён к D2
#define DHTPIN 2
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  // Запускаем Serial Monitor
  Serial.begin(9600);

  // Запускаем датчик
  dht.begin();
}

void loop() {
  // Читаем влажность
  float humidity = dht.readHumidity();

  // Читаем температуру
  float temperature = dht.readTemperature();

  Serial.print("Температура: ");
  Serial.println(temperature);

  Serial.print("Влажность: ");
  Serial.println(humidity);

  delay(2000);
}

const int IN1 = 7;
const int IN2 = 8;
const int SPEED = 9;

void setup() {
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(SPEED, OUTPUT);
}

void loop() {
  // Направление вперёд
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);

  // Скорость примерно 60%
  analogWrite(SPEED, 150);
  delay(2000);

  // Остановка
  analogWrite(SPEED, 0);
  delay(1000);

  // Направление назад
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);

  analogWrite(SPEED, 150);
  delay(2000);

  // Снова остановка
  analogWrite(SPEED, 0);
  delay(1000);
}
Питание мотора обычно подают отдельно. Земля Arduino и драйвера должна быть общей.

Виды алгоритмических конструкций

Большинство программ для Arduino строится из трёх основных алгоритмических конструкций: следование, ветвление и цикл.

1. Следование

Команды выполняются одна за другой сверху вниз.

Пример следования
void loop() {
  // Включаем светодиод
  digitalWrite(8, HIGH);

  // Ждём 1 секунду
  delay(1000);

  // Выключаем светодиод
  digitalWrite(8, LOW);

  // Снова ждём 1 секунду
  delay(1000);
}
Здесь нет выбора. Arduino просто выполняет каждую команду по очереди.

2. Ветвление

Ветвление используется, когда программа должна принять решение: если условие выполняется — сделать одно, иначе — другое.

Пример if / else
void loop() {
  // Читаем кнопку
  int button = digitalRead(2);

  // Проверяем условие
  if (button == LOW) {
    // Если кнопка нажата — включаем светодиод
    digitalWrite(8, HIGH);
  } else {
    // Иначе — выключаем
    digitalWrite(8, LOW);
  }
}
if (...)
Проверяет условие.
else
Выполняется, если условие в if оказалось ложным.

3. Цикл

Цикл позволяет повторять одинаковые действия несколько раз.

Цикл for

Повторить действие 5 раз
void loop() {
  // Переменная i принимает значения 0, 1, 2, 3, 4
  for (int i = 0; i < 5; i++) {
    // Короткий звуковой сигнал
    tone(8, 1000);
    delay(200);

    // Выключаем звук
    noTone(8);
    delay(200);
  }

  // Пауза перед следующим повторением loop()
  delay(2000);
}

Цикл while

Выполнять, пока условие истинно
void loop() {
  // Пока кнопка нажата
  while (digitalRead(2) == LOW) {
    // Светодиод мигает
    digitalWrite(8, HIGH);
    delay(200);

    digitalWrite(8, LOW);
    delay(200);
  }
}

Как выбрать конструкцию

КонструкцияКогда использоватьПример
СледованиеКогда команды должны выполняться одна за другойВключить LED → подождать → выключить LED
ВетвлениеКогда нужно проверить условиеЕсли темно — включить свет
ЦиклКогда действие нужно повторитьМигнуть 5 раз

Код

Автоматический шлагбаум
#include <Servo.h>

const int TRIG = 7;
const int ECHO = 6;

Servo barrier;

float getDistance() {
  // Запускаем измерение
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);

  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);

  // Измеряем время возврата
  long time = pulseIn(ECHO, HIGH);

  // Возвращаем расстояние
  return time * 0.034 / 2;
}

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);

  // Servo подключён к D9
  barrier.attach(9);

  // В начале шлагбаум закрыт
  barrier.write(0);
}

void loop() {
  float distance = getDistance();

  // Если машина ближе 15 см
  if (distance > 0 && distance < 15) {
    // Поднимаем шлагбаум
    barrier.write(90);

    // Держим открытым 3 секунды
    delay(3000);

    // Опускаем
    barrier.write(0);
  }

  delay(200);
}

Как работает

getDistance()
Отдельная функция измеряет расстояние и возвращает число.
distance < 15
Проверяет, приблизился ли объект.
barrier.write(90)
Поднимает сервопривод.
barrier.write(0)
Опускает шлагбаум обратно.

    // Движение обнаружено
    digitalWrite(LED, HIGH);
    tone(BUZZER, 1200);
  } else {
    // Движения нет
    digitalWrite(LED, LOW);
    noTone(BUZZER);
  }

  delay(100);
}

Как работает

digitalRead(PIR)
Читает состояние датчика движения.
motion == HIGH
Означает, что датчик заметил движение.
tone()
Включает звуковой сигнал.

Задания для самостоятельного выполнения

В этом разделе нет готового решения. Нужно самостоятельно выбрать способ подключения и написать программу.

Задание 1. Кнопка и светодиод

Уровень: начальный

Сделайте так, чтобы светодиод загорался только при нажатии кнопки.

Использовать: Arduino, кнопку, светодиод, резистор.

Подсказка: для кнопки можно использовать INPUT_PULLUP.

Задание 2. Автоматический свет

Уровень: начальный

Светодиод должен автоматически включаться, когда становится темно.

Использовать: фоторезистор, резистор, светодиод.

Подсказка: сначала выведите значение фоторезистора в Serial Monitor и подберите порог.

Задание 3. Сигнализация движения

Уровень: средний

При обнаружении движения должен включаться звуковой сигнал.

Использовать: PIR и зуммер.

Подсказка: проверьте состояние выхода PIR с помощью digitalRead().

Задание 4. Парктроник

Уровень: средний

Если расстояние до препятствия меньше 20 см, включайте зуммер.

Использовать: HC-SR04 и зуммер.

Подсказка: после вычисления расстояния используйте условие if.

Задание 5. Автоматический шлагбаум

Уровень: повышенный

При появлении объекта ближе 15 см сервопривод должен поднять шлагбаум, а через несколько секунд опустить.

Использовать: HC-SR04 и Servo SG90.

Подсказка: сначала проверьте работу датчика и сервопривода отдельно.
